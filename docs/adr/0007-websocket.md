# ADR-0007: WebSocket

- 状態: Accepted（2026-09-27）

## 制約（公式クォータ, 2026-09 確認）

API Gateway WebSocket: idle 10 分、最大接続 2 時間、フレーム 32KB、メッセージ 128KB。

## 決定

- 通知は「ヒント」。クライアントは接続確立のたびに HTTP で全状態を再同期するので、切断中の取りこぼしを許容する。
  加えて 2 分毎の定期再同期、受信中 Transfer は 20 秒ポーリングを保険にする。
- アプリレベル ping（`{"action":"ping"}` → `pong`）を 4 分毎。30 秒応答がなければ切断扱い。
- 110 分で自分から張り直す（2 時間の強制切断を待たない）。
- 再接続は指数バックオフ（1s→60s）+ ジッター。
- スリープ復帰はタイマーの経過時間の飛び（>30s）で検出して即張り直し。
- 通知は 32KB フレームに収まるよう小さく保つ（chunks_ready は 100 件ずつ分割）。
- サーバーは通知送信失敗（Gone）で接続レコードを掃除するが、接続後 30 秒以内は消さない
  （`$connect` 完了前の送信失敗は切断ではないため。ローカル結合テストでこの競合を実際に踏んで修正）。
- 接続は CloudFront の `/ws` → API Gateway WebSocket（ステージ名 `ws`）。認証は `Authorization` ヘッダ。

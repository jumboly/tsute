# ADR-0010: CI/CD — GitHub Actions + OIDC

- 状態: Accepted（2026-09-27）

## 決定

| Workflow | トリガ | 内容 |
|---|---|---|
| `ci.yml` | push/PR | fmt / clippy / `cargo test --workspace`（macOS ランナー）、cfn-lint、Lambda の arm64 ビルド |
| `deploy-backend.yml` | main への push（Backend/infra のパスのみ）/ 手動 | OIDC で `tsute-github-app-deploy` を引き受け `infra/deploy.sh <env>` → `/api/health` スモーク |
| `desktop.yml` | main への push（apps/crates）/ 手動 | `cargo tauri build` で .app を作り artifact 化。`TSUTE_DEFAULT_BASE_URL` を Environment Variables から注入 |
| （Blog repo）`deploy.yml` | Blog repo の push | Astro build → Blog バケットへ sync → invalidation。アプリ Backend には触れない |

- AWS 認証は GitHub OIDC → STS の短期クレデンシャルのみ。長期アクセスキーは作らない。
- CI ロールは CloudFormation 操作・`tsute-cfn-exec` の PassRole・成果物アップロードだけを持ち、
  リソース作成権限は CloudFormation 実行ロール側に閉じ込める（最小権限と監査のしやすさ）。
- 信頼ポリシーは `repo:<owner>/<repo>:environment:*` に限定。GitHub Environment（test / production）に
  承認ルールと Variables を持たせる。Blog ロールは `environment:production` に完全一致で限定する。
- GitHub の **immutable OIDC subject** が有効なリポジトリでは `sub` が
  `repo:<owner>@<ownerId>/<repo>@<repoId>:...` になり、旧形式の条件と一致しない（Blog で実際に
  AssumeRoleWithWebIdentity が拒否された, 2026-09-27）。リポジトリ指定のパラメータには
  `gh api repos/<owner>/<repo>/actions/oidc/customization/sub` の `sub_claim_prefix` から `repo:` を除いた値を入れる。
  アプリ側（bootstrap の `GitHubAppRepo`）も immutable 形式に更新済み（2026-09-29, #3）。
- `deploy-backend.yml` の設定値は、`AWS_REGION` だけ Variables、`AWS_DEPLOY_ROLE_ARN`, `TSUTE_APP_DOMAIN`,
  `TSUTE_CERT_ARN`, `TSUTE_GITHUB_BLOG_REPO`, `TSUTE_GITHUB_APP_REPO` は Environment の Secrets（2026-09-29 変更）。
  秘密情報ではないが、public リポジトリの Actions ログに独自ドメインやアカウント ID を載せないため（Secrets はマスクされる）。
  独自ドメインは Certificate Transparency ログや DNS からは分かるので、隠せるのはこのリポジトリのログ経由までである。
  値の正本は手元の `infra/env/<env>.env`（GitHub 上では値を読み返せない）。CI の `infra/deploy.sh` は値をそのまま
  CloudFormation に渡すため、`.env` と食い違うと edge スタックが書き換わる（例: Blog リポジトリが空だと Blog ロールが消える）。
  `AWS_REGION` は `configure-aws-credentials` の入力で、マスクするとログ全体が読みにくくなるので Variables のまま。
- その他のワークフロー（`desktop.yml` の `APP_BASE_URL`、`deploy-web.yml`、Blog 側の `BLOG_BUCKET`,
  `CLOUDFRONT_DISTRIBUTION_ID`）は Variables。

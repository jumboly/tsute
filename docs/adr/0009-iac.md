# ADR-0009: IaC — CloudFormation

- 状態: Accepted（2026-09-27）

## 決定

素の CloudFormation（YAML）+ `aws cloudformation deploy`。

- 理由: 追加ツールチェーン（CDK の Node 依存・bootstrap スタック、Terraform の state 管理）が不要で、
  AWS CLI だけでデプロイ・CI が完結する。個人利用規模ではテンプレートの抽象化の利点が小さい。
- 検証: `uvx cfn-lint infra/cloudformation/*.yaml`（CI でも実行）。

## スタック分割と所有責務

| スタック | リージョン | 所有 | 内容 |
|---|---|---|---|
| `tsute-bootstrap` | backend と同じ | 管理者が手動で 1 回 | Lambda 成果物バケット、CFN 実行ロール `tsute-cfn-exec`、GitHub OIDC Provider、アプリ CI ロール |
| `tsute-<env>-backend` | 例: ap-northeast-1 | アプリ repo | DynamoDB、転送用 S3（Lifecycle 8 日）、Lambda（api/admin）、HTTP API、WebSocket API（stage `ws`） |
| `tsute-<env>-edge` | us-east-1 | **アプリ repo（共有インフラの所有者）** | CloudFront（単一 FQDN）、Blog 用 S3 + OAC、Blog CI ロール |

- Blog リポジトリは edge スタックが作る Blog バケットへの `s3 sync` と invalidation だけを行う（ロールもそれだけ許可）。
  Blog の更新でアプリの Backend は再デプロイされない。
- ACM 証明書は `infra/request-cert.sh` で CLI 発行（外部 DNS に検証 CNAME をユーザーが手動追加）。
  CloudFormation で作ると検証完了までスタックが待ち続けるため分離した。
- 親ゾーンの DNS 事業者が「名前解決できない CNAME 値」を拒否する場合（ACM 検証用 CNAME の値は A を持たない。
  さくらのドメインコントロールパネルで実際に拒否された）は、アプリ用サブドメインだけを Route 53 に委任する。
  `infra/route53-subdomain.sh <env>` がホストゾーン作成・検証用 CNAME・CloudFront への ALIAS を UPSERT し、
  親ゾーンに追加すべき NS を表示する。証明書と同様にスタック外で管理する（CFN 実行ロールに Route 53 権限を
  足すには管理者の bootstrap 更新が必要になり、ゾーン自体は環境の寿命より長く保ちたいため）。
  ホストゾーンは月 $0.50 程度の継続課金（ユーザー了承済み, 2026-09-27）。
- ドメイン名は `infra/env/<env>.env`（gitignore 済み）と AWS 上のリソースにだけ置き、リポジトリには書かない。
- カスタムドメイン未設定でも `*.cloudfront.net` で全機能が動く（DNS 設定前に検証できる）。
- Blog の存在しない URL は、デフォルトビヘイビアだけに付けた Lambda@Edge（origin-response,
  `tsute-<env>-blog-notfound`）が S3 の 404 を Blog の `/404.html`（ステータス 404, `max-age=300`）に差し替える。
  CustomErrorResponses はディストリビューション全体に効き API の JSON エラーまで置き換わり、CloudFront Functions は
  オリジンが 4xx を返すと実行されないため（いずれも公式ドキュメントで確認, 2026-09-27）。S3 に 404 を返させるため
  OAC に `s3:ListBucket` を許可し、本物の 403（権限ミス）は差し替えない。初回に必要なサービスリンクロール
  `AWSServiceRoleForLambdaReplicator` は CFN 実行ロールに権限がないため CLI で一度だけ作成した。
  関数コードを変えたら `BlogNotFoundVersion` の Description を更新する（Version はコード変更を検知しない）。
  削除時は各リージョンの複製が消えるまで数時間かかることがある。
- `/ws` は API Gateway WebSocket のステージ名を `ws` にすることで URI 書き換えなしにステージへ届く。
- API のスロットリング（既定 50 rps）でトークン漏えい時のコスト上限を抑える。
